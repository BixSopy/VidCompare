# Security policy

Report a vulnerability privately through GitHub: **Security > Report a vulnerability** on this repository. Do not open a public issue for it. Expect an answer within 7 days.

VidCompare opens files you choose, runs `ffprobe`/`ffmpeg` on them, and parses `.torrent` files, magnet links and pasted MediaInfo reports. Reports about crashes or unsafe handling of crafted files are in scope.
