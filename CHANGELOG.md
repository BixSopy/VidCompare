# Changelog

## 6.0.0
- Interface, reports, CSV exports and CLI in 10 languages (en, zh, hi, es, ar, fr, bn, pt, ru, id), with a language setting and right-to-left layout for Arabic.
- Preferred track language works for all ten languages.
- Translations are machine-made and need native review.
- Open-source release: MIT license, FFmpeg no longer bundled, installer, CI.

## 5.0.0
- Faster, more reliable frame extraction and VMAF on heavy 4K remuxes; one ffprobe call per file; accessibility and contrast fixes.

## 4.0.0
- Web interface (pywebview), library scan, history, upgrade suggestions, device profiles.
